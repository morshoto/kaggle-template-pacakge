# Findings

Store durable experiment results and audit reports here. Use the [experiment index](../../experiments/README.md) as the navigation page, and link each finding there with its stable experiment ID.

- [`findings_template.md`](findings_template.md): controlled experiments and policy changes.
- [`submission_audit_template.md`](submission_audit_template.md): package identity, runtime, and promotion audits.

Name findings with their experiment or submission ID and a short topic, for example `exp-001-data-quality.md`. Keep generated logs and episode-level records under ignored `artifacts/`; summarize only the evidence needed to make or revisit a decision.
